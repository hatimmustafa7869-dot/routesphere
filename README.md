# RouteSphere Telecom - Wholesale VoIP & Carrier Solutions

A carrier-grade wholesale voice marketing and routing platform replica built for wholesale VoIP termination, direct PTT interconnects, and Session Border Controller (SBC) media gateways.

## Features
- **Hero & SBC Telemetry Console**: Live Session Border Controller node telemetry with interactive audio spectrum visualizer.
- **Interactive Carrier Topology Map**: Clickable global PoPs (Frankfurt, London, New York, Singapore, Tokyo, Dubai, São Paulo, Johannesburg, Sydney) with live latency, ASR, and PDD metrics.
- **Automated FAS & Route Probe Engine**: Interactive IVR probe testing tool calculating ASR, PDD, and PESQ MOS audio scores.
- **Rate Intelligence Matrix**: A-Z wholesale rates table with instant prefix search and dynamic CSV download.
- **B2B Solutions & Leadership**: Tailored wholesale solutions and leadership profile for Founder & CEO H B.
- **Interactive Portals**: Functional modals for Request Wholesale Rates, Bilateral Peering Swaps, and Softswitch Portal Login.
- **Fully Responsive & Dark Mode**: Tailored for mobile, tablet, and desktop with a fixed bottom navigation bar.

## Tech Stack
- HTML5 / CSS3 / Vanilla JavaScript
- Tailwind CSS (CDN)
- Google Fonts (`Inter`, `JetBrains Mono`, `Space Grotesk`)
- Lucide Vector Icons (inline SVG)

## Getting Started
Open `index.html` in any modern web browser or host with GitHub Pages, Vercel, or Netlify.
